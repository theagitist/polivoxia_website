The colour of coordinates

Every digital file is homeless. It knows the address of the machine it came from but nothing about the world: no place, no height, no moment. ColourSpace hides all three inside the colours of ordinary pixels, so an image can carry an exact position the way it already carries a picture.

What follows reads nine such vectors back from colour alone: four places on a turning globe, three heights above the Earth, two instants in time. Nothing is sent to any server; every value is decoded here, in your browser, from the pixels themselves.

What eight bytes can hold

The nested, logarithmic design gives one vector both vast range and fine precision. Each bar is the span a single 8-byte vector addresses, in orders of magnitude.

vSpace~10 orders of magnitude
6 mm40,000 km (whole Earth)
vHeight~17 orders of magnitude
2 µm1 AU (150 million km)
dTime~14 orders of magnitude
0.23 s256,000 years

vHeight alone spans about seventeen orders of magnitude, from microns to the distance of the Sun, and stays exact across all of it. That is what a nested, self-similar address buys.

Under the hood

The piece hides its machinery, but none of it is magic. Open any panel for the real code that runs, and the reason it is shaped that way.

The motive is simple. A photograph cannot say where it was taken; a message cannot say when it means; a record cannot point at a place. Location today belongs to the network, not the data. ColourSpace tries to give data a body in space and time, carried by the data itself, so a vector still means something outside the system that made it.

Why read the colour, not the canvasdecode

The obvious way to read pixels back is a 2D <canvas>. It is also wrong here: a canvas premultiplies alpha, so it quietly corrupts any pixel whose alpha channel is real data rather than transparency — and in every vector, bytes 3 and 7 are data. So the underlay PNG is inflated byte-for-byte instead, straight from its compressed stream.

// A 2D canvas premultiplies alpha, corrupting bytes 3 and 7.
// Inflate the PNG's own bytes instead — lossless.
const ds  = new DecompressionStream('deflate');
const raw = new Uint8Array(await new Response(
    new Blob([idat]).stream().pipeThrough(ds)).arrayBuffer());
// every channel survives exactly, alpha included.
Why a byte prefix is already a regionvSpace

vSpace tiles the sphere with HEALPix, nested: each byte chooses one of 256 equal-area tiles, coarse to fine. That nesting is the whole trick. The first N bytes of a vector are a coarser tile containing it, so searching “everything near here” is a prefix match on a sorted list — no spatial index, no distance loop.

pix    = ang2pix(theta, phi, order=30)  # 64-bit tile index
region = pix >> (8 * (8 - n))          # drop fine bytes -> coarser tile
# same prefix  ==  same region. "near" is a range scan.
Why the vectors are just integersvector math

A vector has to be operable, not just readable. Because a uniform 8-byte vector is simply a big-endian 64-bit integer, subtracting two places gives a real spatial offset, and adding an offset gives a new real address — commutative, with carry and borrow crossing byte boundaries for free. No vector library; the CPU already has one.

a    = int.from_bytes(v1, 'big')
b    = int.from_bytes(v2, 'big')
diff = (a - b).to_bytes(8, 'big')   # place - place = an offset
# add that offset to a third place to land somewhere real.

The carrier

primary layer

This is a normal picture. The nine vectors above are hidden on a layer beneath it, unseen.

Every hidden vector becomes one note, read straight from the image: its pitch follows the value it holds (a higher place, a higher altitude, a later year sounds higher), and its timbre follows its kind. The picture, heard.

waveform
How the sound is mappedsonification

The nine vectors play left to right, in the exact order they sit in the image. As each one sounds, a bright band marks the two pixels that carry it, and a dot rises to the note's pitch.

Pitch is the value the vector holds, folded onto a minor-pentatonic scale (base near D3, about three octaves) so every note stays consonant:

vSpace   latitude   south -> low,   north -> high
vHeight  altitude   ground -> low,  orbit -> high (log)
dTime    year       ancient -> low, modern -> high

Timbre is the kind of vector: triangle for a place, sine for a height, square for a moment. Nothing is composed in advance; the melody is simply the image, read as tone.

ColourSpace & dTree are a research prototype, made as an academic project in Manuel Pina's workshop, exploring how physical and digital reality might share one address. Everything here was decoded in your browser from colour alone: the raw PNG bytes are inflated directly, never through a 2D canvas, which premultiplies alpha and would corrupt the data. The whole idea leans on Cantor's 1878 proof. A prototype and a set of ideas, not a finished standard.
